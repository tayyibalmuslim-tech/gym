# 🏋️ دفتر التمرين — أمامي / خلفي (دورة 6 أيام)

> ⚠️ شرح طريقة الأداء والنصائح والأخطاء الشائعة داخل التطبيق مكتوبة بمساعدة الذكاء الاصطناعي وقد تحتوي أخطاء — يُرجى المراجعة مع فيديو MuscleWiki قبل التنفيذ.

تطبيق في ملف واحد (`index.html`) لتسجيل التمارين على نظام **أمامي / خلفي (Anterior / Posterior)**: يومين تمرين ثم يوم راحة، مع **حسابات ومزامنة سحابية**: كل شخص ليه جدوله وتسجيلاته.

## المزامنة والحسابات
- تسجيل الدخول إجباري بإيميل وباسورد، على نفس مشروع Firebase بتاع "البناء المنهجي" و"مصحف التدبر" (`mazen-productivity-bab1c`).
- بيانات تطبيق الجيم منفصلة تماماً عن التطبيقات التانية:
  - `gym_users/{uid}`: البيانات الشخصية، والدورة الحالية، وتسجيلات كل دورة.
  - `gym_plans/{uid}_{رقم الدورة}`: جدول كل دورة.
- نسخة من البيانات بتتحفظ على الجهاز، فالتطبيق بيشتغل لو النت فصل في الجيم، وبيتزامن لما يرجع.
- التسجيلات القديمة (قبل نظام الحسابات) بتتربط بأول حساب يدخل على نفس الجهاز.

### ⚠️ قواعد Firestore المطلوبة (تتضاف مرة واحدة)
في Firebase Console ← Firestore ← **Rules**، ضيف القواعد دي جنب القواعد الموجودة:
```
match /gym_users/{uid} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}
match /gym_plans/{docId} {
  allow read, write: if request.auth != null
    && docId.matches(request.auth.uid + '_[0-9]+');
}
```

## الجداول لكل شخص
- كل شخص بيكتب **كود جدول** في بياناته (مثلاً `mazen`).
- الجداول بتترفع في `plans/<الكود>/cycle-<N>.json`.
- من التطبيق: **حسابي والملفات ← حدّث جدولي من المستودع**.
- أو يستورد ملف الجدول يدوياً.

| المسار | الوظيفة |
|---|---|
| `index.html` | التطبيق كامل (الخطة الافتراضية وصورة الجسم مضمّنين فيه) |
| `plans/default/cycle-1.json` | دورة المعايرة الافتراضية لأي مستخدم جديد |
| `plans/default/cycle-2.json` | دورة البناء الافتراضية (أوزانها بتتحسب من تسجيل الدورة 1) |
| `plans/mazen/cycle-N.json` | جداول مازن |

## الدورة (6 أيام)
| اليوم | الجلسة |
|---|---|
| 1 | أمامي A — تقيل (سكوات، بنش، كتف) |
| 2 | خلفي A — تقيل (ديدلفت، تجديف، سحب) |
| 3 | راحة نشطة |
| 4 | أمامي B — حجم |
| 5 | خلفي B — حجم |
| 6 | راحة كاملة |

## التقدم التلقائي
لما تحمّل دورة فيها `autoProgress`، التطبيق بيحسب كل وزن من تسجيلك في الدورة اللي فاتت:
- كمّلت أعلى عدد عدات في كل المجموعات ← الوزن يزيد (+5 رجل، +2.5 علوي، +1–2 دمبل).
- ما كمّلتش ← نفس الوزن.
- ما سجّلتش ← وزن تقديري.

تسجيلات نظام PPL القديم بتتحفظ في "أرشيف" وتقدر تفتحه من حسابي والملفات ← الدورات.

> ملفات `plans/` عامة على GitHub، فاستخدم كود مش اسم كامل. التسجيلات نفسها خاصة على حساب كل شخص.

## طريقة الاستخدام
1. ادخل بحسابك، ولو أول مرة اكتب بياناتك.
2. من **الدورة** اختار اليوم، وسجّل الوزن والعدات لكل مجموعة، واضغط ✓. مؤقت الراحة هيشتغل لوحده.
3. كل تمرين فيه: هتحس بيه فين، وخريطة العضلات، وزرار **النصائح والأداء** (طريقة الأداء، وأفضل أداء، ونصائح، وأشهر أخطاء اللاعبين، ورابط MuscleWiki).
4. في آخر الدورة: صدّر ملف JSON وابعته عشان تتبني عليه الدورة الجاية.
