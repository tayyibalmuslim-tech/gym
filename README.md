# 🏋️ دفتر التمرين — PPL × 2 (دورة 8 أيام)

> ⚠️ شرح طريقة أداء التمارين داخل التطبيق مكتوب بمساعدة الذكاء الاصطناعي وقد يحتوي أخطاء — يُرجى المراجعة مع فيديو MuscleWiki قبل التنفيذ.

تطبيق في ملف واحد (`index.html`) لتسجيل تمارين مازن على نظام **Push / Pull / Legs مرتين كل 8 أيام** (6 أيام تمرين + يومين راحة).

## طريقة الاستخدام
1. افتح التطبيق من GitHub Pages أو افتح `index.html` مباشرة.
2. من **الدورة** اختار اليوم → سجّل **الوزن والعدات لكل مجموعة** واضغط ✓.
   - لو سبت الخانة فاضية وضغطت ✓ بياخد وزن/عدات المجموعة اللي قبلها (أو المقترح).
   - بعد ✓ بيشتغل **مؤقت الراحة** لوحده.
3. زرار **طريقة الأداء** بيعرض: صورة الجسم والعضلات المستهدفة متعلّمة (أحمر = أساسية، برتقالي = مساعدة) + الخطوات + رابط MuscleWiki.
4. في آخر الدورة: **استلام وتصدير ← تصدير JSON** وابعت الملف لـ Claude.
5. Claude يرفع `plans/cycle-2.json` → من التطبيق اضغط **حمّل الدورة 2 من المستودع** (أو استورد الملف يدويًا).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كامل (الخطة الافتراضية وصورة الجسم مضمّنين فيه) |
| `plans/cycle-N.json` | خطة كل دورة (`kind: "plan"`) |
